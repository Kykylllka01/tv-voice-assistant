## [1.0.0] — 2026-10-28

Первый публичный выпуск: название «Сфера», готовый APK в релизах.

### Добавлено
- **Управление телевизором:** открыть любое установленное приложение, поиск на YouTube, громкость
  (уровень, тише, громче, без звука).
- **Напоминания и таймеры:** «через 15 минут», «в 21:30». Окно со звуковым сигналом и голосом появляется
  поверх любого экрана; после перезагрузки телевизора напоминания восстанавливаются.
- **Карточка погоды:** температура сейчас и на 7 дней с иконками, голосом — только суть (Open-Meteo,
  без ключа).
- **Источники:** OK на ответе показывает источники по одному с QR-кодом для телефона, ещё одно OK
  открывает статью в браузере телевизора. QR-кодировщик свой, сверен с эталонной библиотекой.
- Настоящие иконки сайтов на плашке источников.
- Подсказки для ИИ-агентов: [PROMPT.md](PROMPT.md) (установка на телевизор) и [AGENTS.md](AGENTS.md)
  (работа с кодом).

### Изменено
- **Название «Сфера»**, новая карточка в лаунчере.
- **Настройки** в стиле окна помощника: шапка с шаром, разделы на графитовых карточках, главная кнопка
  акцентная, экран открывается сверху.
- **Окно:** длинный вопрос показывает свой конец, пока звучит; ответ вмещает вдвое больше и листается
  стрелками вверх и вниз.
- **Подсказки** — по одному действию на кнопку, без «затем»; значки стрелок как на пульте.
- **Закрытие** только после 45 секунд бездействия; любое нажатие продлевает, источник с QR не закрывается.
- **«Назад»** во время прослушивания или ответа отменяет шаг, а не закрывает окно.
- Выпуск подписан собственным ключом.

### Исправлено
- OK иногда закрывал окно вместо своего действия.
- Номер источника отрывался на отдельную строку; недописанная ссылка «[2» мелькала при печати.
- Плюсы вместо пробелов в поиске YouTube.
- Пять путей к падению: опечатка в адресе сервера, ошибка инструмента, запуск удалённого приложения,
  гонка с движком голоса после закрытия, сбой звукового сигнала.
- Повреждённый список напоминаний больше не стирается целиком; напоминание не теряется, если его не
  удалось показать.

### Безопасность
- Напоминание показывает только будильник самого приложения: другие приложения не могут заставить
  телевизор говорить от имени «Сферы».
- После поиска в том же ответе модель не может менять память и напоминания: страница из выдачи не
  подсунет «факт»; текст из инструментов для модели — сведения, а не указания.
- В браузер и QR-коды попадают только веб-ссылки (http, https).
- Ключи не попадают в журнал; сервер модели принимается только по https.
- Модель не сохраняет пароли, коды, номера карт и документов.

### Производительность
- Список приложений не перебирается в главном потоке на каждом вопросе.
- Печать ответа перерисовывает текст только при новой букве; анимации в покое — 30 кадров в секунду.
- Соединение с моделью переиспользуется между раундами; ключ шифрования, QR-коды и неудачные иконки
  кэшируются.

## [0.1.0] — 2026-10-27

Первая рабочая версия.

### Добавлено
- Окно поверх любого экрана, даже HDMI, по кнопке микрофона на пульте (роль ассистента).
- Ответы DeepSeek с потоковой печатью и озвучкой по предложениям.
- Поиск в интернете через Tavily с номерами источников в тексте; режим свежих новостей с датами
  публикаций.
- Погода через Open-Meteo без ключа.
- Память: «запомни, я живу в Казани» — факты на телевизоре, видны и правятся в настройках; разговор
  продолжается 30 минут после закрытия окна.
- Выбор из пяти онлайн-голосов Google с прослушиванием.
- Честный системный промпт: не делает вид, что умеет то, чего не умеет.
- Настройки с ключами, зашифрованными в Android Keystore, и проверочным вопросом.

### Исправлено
- Окно закрывалось посреди длинного вопроса по таймеру.
- Окно подвисало на секунды от нажатий во время прослушивания (вызовы движка голоса шли в главном потоке).
- Модель говорила «запомнил», не вызвав инструмент.
